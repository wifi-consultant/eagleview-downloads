# Wingman Eagleview - Downloads

Public download location for the **Wingman Eagleview** Windows installer.

- Installers are published here as GitHub **Release** assets (`Eagleview-Setup-<version>.exe`),
  one release per published version (`v<version>`).
- The in-app updater reads `https://software.launchwingman.com/eagleview/latest.json`, which names
  the current release here, verifies the installer's SHA-256 and runs it (a per-user install, no admin).
- Part of the Wingman family at **https://launchwingman.com** (Wingman for Windows, Wingman One,
  Wingman Eagleview).

This repository contains **no source code**, only the compiled installer, so anyone can download
Wingman Eagleview. The Eagleview source repository is private.
